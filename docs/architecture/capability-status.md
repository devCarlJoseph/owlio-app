# Capability status

Source review: 17 November 2026. Source and configuration establish implementation; browser reads and mocked tests establish different verification scopes.

## Operating mode

Auth/session and role guards always run. The compatibility export in `src/lib/api-mode.ts` is true; it no longer controls the guards or providers. There is no authentication preview bypass or local onboarding route. Original workspace layouts and browser-local tools are restored behind these guards.

`ApiWorkspaceContent` renders the original page adapters by default. **Account records** (`?source=account`) opens the separate connected overview, student subjects/tasks/notes, notifications, schedule, and tutor sessions. Browser-local work is accessible in the original tools without automatic import. Built-in workspace demo collections have been cleared while preserving the UI: subjects, notes, tasks, Study Spaces/discovery/room occupants, room tasks/lockers, classwork, library resources, notification examples, calendar examples, and meeting layout participants/whiteboard seeds. Existing storage notices still identify unconnected features. Untouched legacy local seeds are hidden and backed up before the next normal save; edited seeds remain user work. This cleanup does not connect additional APIs. See [data cleanup and integration entry points](../DEMO_DATA_REMOVAL.md).
