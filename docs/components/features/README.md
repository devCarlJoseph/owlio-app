# Feature component guides

This directory mirrors **every directory** in `src/components/features/` by name. Each active domain has a detailed `README.md`, `SOURCE_INDEX.md`, and `source/` containing `.txt` copies of the current implementation organized by the *proposed* component breakdown. Nested `README.md` files point back to their owning feature plan; empty source domains have short placeholder guides. Personal workspace also has detailed subfeature plans.

The code copies are not compiled or refactored. Their proposed `source/` subfolders may differ from the current source layout; consult each `SOURCE_INDEX.md` for the original path. [All feature plans and commit messages](../../component-breakdowns.md).
