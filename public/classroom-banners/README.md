# Owlio classroom banners

Original illustrations created for this project with the built-in ImageGen tool. These are bundled static assets, not images generated when a user creates a classroom. The interior chooses a stable variant from the permanent classroom ID. Existing classroom-list thumbnails use their separate cover selection.

Files: `learning-studio.png`, `discovery-lab.png`, `creative-ideas.png`.

## Generation prompts

### Learning studio

Use case: stylized-concept. Create an original premium wide classroom banner illustration for Owlio, an independent and classroom learning product with an indigo/violet brand. Landscape 3:1 ratio, ideally 1536 by 512 or wider. Soft tactile 3D paper sculpture / refined editorial illustration with crisp shapes, gentle dimensional shadows and polished details. Background pale lavender (#eef0ff) with restrained violet (#6534ef), indigo and periwinkle accents. Theme: a cozy learning studio, sculptural open notebook, stacked books, elegant desk lamp, pencil and tiny star-like learning sparks. Compose all prominent objects in the RIGHTMOST 45 percent, with leftmost 55 percent a quiet nearly uniform very pale lavender space where the application will overlay its real classroom title. Keep objects within central vertical 65 percent so this image can crop to a very wide short banner. Original Owlio-only artwork; do not reproduce Google Classroom art. No text, no letters, no logos, no watermark, no UI, no buttons. Mature, welcoming, beautifully balanced, suitable for all school subjects. Background opaque.

### Discovery lab and creative ideas

Each uses the following prompt, replacing `[scene]` with its scene below:

Use case: stylized-concept. Original Owlio classroom banner illustration, landscape 3:1 aspect ratio. Premium soft tactile 3D paper sculpture style, crisp precise shapes, beautifully polished gentle dimensional shadows. Scene: [scene]. Pale nearly uniform lavender background #eef0ff; indigo, violet #6534ef and periwinkle objects, cream details and very restrained warm gold accents. Composition: all objects grouped in RIGHTMOST 45 percent; leftmost 55 percent almost empty quiet pale lavender for real classroom title rendered later in HTML. Keep primary objects inside central vertical 65 percent so a short wide crop works. Mature yet warm and welcoming, no UI, no text, no lettering, no logo, no watermark. Original art for Owlio only, do not copy Google Classroom. Opaque background.

- Discovery lab scene: a delightful discovery lab, a small telescope, an orbiting planet model, a sculptural atom, a small friendly violet owl beside an open notebook
- Creative ideas scene: a creative learning corner, a laptop showing abstract geometric shapes (no writing), a glowing sculptural lightbulb, stacked notebooks and a small friendly violet owl
